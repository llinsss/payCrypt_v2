API documentation for the Tagg@d backend.

Authentication

Most endpoints in the Tagg@d API are protected. We use JWT Bearer tokens for user authentication and API Keys for server-to-server integrations.

  • JWT Bearer Token: Obtain this by logging in via /api/auth/login. Pass it in the Authorization header as Bearer <your_token>.
  • API Key: If configured, pass your API key via the x-api-key header.

Getting Started

Follow this complete payment flow to integrate with the Tagged API:

1. Register a User

Create a new user account:

POST /api/auth/register
Content-Type: application/json

{
  "email": "[email protected]",
  "password": "SecurePassword123!",
  "firstName": "John",
  "lastName": "Doe"
}

2. Get JWT (Login)

Retrieve your authentication token:

POST /api/auth/login
Content-Type: application/json

{
  "email": "[email protected]",
  "password": "SecurePassword123!"
}

Extract the token from the response and use it in subsequent requests.

3. Create a Wallet

Initialize the user's multi-chain wallet:

POST /api/wallets/create
Authorization: Bearer <your_token>
Content-Type: application/json

{
  "chainId": "base-sepolia"
}

4. Send a Payment

Send funds using a recipient's @tag or wallet address:

POST /api/withdrawals/send
Authorization: Bearer <your_token>
Content-Type: application/json

{
  "recipientTag": "@sarah_lagos",
  "amount": 50,
  "currency": "USDC",
  "network": "base"
}
